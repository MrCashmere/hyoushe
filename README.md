# 米悠社（hyoushe）

移植版米游社，目前功能基本全量。

**非开源项目，Github 仓库仅在 Release 提供安装包分发。**

**注意：以下内容部分需要升级至`2.0.0`版本及以上，若Release暂无该版本请等待更新**

全能型二游社区类 App，现在已经支持：

---

## 支持的社区与游戏

### 米游社
- 90% 的功能：看帖、搜索、下载、互动、私信、通知、各类小工具
- 支持米游全游戏签到
- 社区签到支持：大别野、原神、崩坏：星穹铁道、绝区零、崩坏3、未定、崩坏学园2、崩坏：因缘精灵
- 支持原神，绝区零直接获取抽卡记录，崩坏：星穹铁道通过云游戏获取抽卡记录。[查看免责声明](#免责声明)
- 支持扫码登录其他设备 / 游戏
- 支持桌面卡片，现已支持自定义

### HoYoLab（国际服）
- 看帖、搜索、下载、各类小工具
- 支持帖子自动匹配对应语言
- 支持评论翻译（HoYoLab官方翻译行为，可能不准确）
- **不支持签到**
- 支持桌面卡片，现已支持自定义

### 云游戏（国内官服）
- 原神
- 崩坏：星穹铁道

### 库街区
- 支持看帖、搜索、看视频（需要登录）、下载图片 / 视频
- 支持评论、回复、点赞
- 支持打开其他人的主页
- 鸣潮签到（战双不支持）
- 部分H5工具

### 塔吉多
- 支持看帖、搜索、看视频、下载图片 / 视频
- 支持评论、回复
- 支持打开其他人的主页
- 异环签到
- 部分H5工具

### 森空岛
- 支持看帖、搜索、看视频、下载图片 / 视频
- 支持评论、回复、点赞
- 支持打开其他人的主页
- 明日方舟、明日方舟：终末地签到
- **以上功能均需要登录**
- 部分H5工具

> **注意**：米游社支持表情显示表情，其他三家已支持表情，HoYoLab尚未完成支持适配。

---

## 特色功能（对比官方 App）

- 支持原神、崩坏：星穹铁道的云游戏（需要额外登录）
- 支持一键签到（多游戏、多社区）
- 支持直接获取抽卡记录和抽卡链接（**注意：链接尽量不要发给别人**）
- 支持导出 UIGF 社区通用规范的抽卡记录文档
- 支持SDR显示HDR，同时支持下载时转换为HDR Vivid
